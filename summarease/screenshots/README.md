# Screenshots & Image Placeholders

This folder contains placeholder assets you can use on the landing page until real screenshots are available.

Files
- desktop-hero.svg — 1440×900 hero placeholder
- desktop-fullpage.svg — 1440×2400 full-page placeholder
- mobile-hero.svg — 390×844 mobile hero placeholder
- mobile-fullpage.svg — 390×2200 mobile full-page placeholder
- og-image-1200x630.svg — Open Graph share image placeholder
- images.json — content map with alt text and suggested generation prompts

How to replace
1) Generate WebP/AVIF replacements at the same aspect ratios.
2) Keep filenames the same for a drop-in swap, or update references in your builder/template.
3) Recommended: specify width/height attributes and use lazy-loading for non-hero images to avoid CLS.

Alt text
Use meaningful alt text describing the function of the image (e.g., "Sat-Brain dashboard summarizing a PDF with a Q&A panel") rather than its appearance.
