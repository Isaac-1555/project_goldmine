# Sat‑Brain brand assets

This folder contains the Sat‑Brain logomark concepts and favicon.

Contents
- satbrain-mark-a.svg — Orbital Core (gradient)
- satbrain-mark-a-mono.svg — Orbital Core (monochrome)
- satbrain-mark-b.svg — Dish Lobe (gradient)
- satbrain-mark-b-mono.svg — Dish Lobe (monochrome)
- satbrain-mark-c.svg — Monogram Orbit (gradient)
- satbrain-mark-c-mono.svg — Monogram Orbit (monochrome)
- satbrain-mark-d.svg — Bilobed Brain + Orbit (gradient)
- satbrain-mark-d-mono.svg — Bilobed Brain + Orbit (mono)
- satbrain-mark-e.svg — Neural Nodes Brain + Ring (gradient)
- satbrain-mark-e-mono.svg — Neural Nodes Brain + Ring (mono)
- satbrain-mark-f.svg — Network Graph Brain (black/white, no gradient)
- satbrain-favicon-light.svg — Favicon for light mode (black)
- satbrain-favicon-dark.svg — Favicon for dark mode (white)

Usage
- Prefer the gradient versions on dark backgrounds.
- Prefer the -mono versions when you need a single-color icon (inherits currentColor).
- For React usage, see src/components/brand/SatBrainMark.tsx.
